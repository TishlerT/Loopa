# Project Brief — Loopa

## Vision
A music creation app for iOS that enables users to record, layer, and loop musical performances in real-time.

## Core Features
- Multi-instrument keyboard (piano, drums, synths, etc.)
- Multi-track loop recording with quantization
- Vocal recording with microphone
- Real-time playback with pause/resume
- BPM control and metronome
- Session save/load

## Quality Standards
- All interactive UI elements must have accessibility identifiers
- Tests should pass before merging changes
- Use CLI for all Xcode operations
- Follow SwiftUI best practices

## Target Platform
- iOS 17.0+
- iPhone and iPad (landscape orientation)

## Tech Stack
- SwiftUI for UI
- AVAudioEngine for audio
- XcodeGen for project generation
- XCUITest for UI testing
